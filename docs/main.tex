\begin{abstract}
El presente documento describe la arquitectura técnica formal, la especificación de protocolos y las garantías deterministas del Orquestador Stateless de Negociación A2A. El sistema opera sobre ASP.NET Core y .NET 9, mediando transacciones comerciales automatizadas entre agentes inteligentes bajo el estándar Agent-to-Agent (A2A) mediante invocación remota JSON-RPC 2.0. Se detalla la estructura desacoplada de cinco capas, la FSM determinista en código C\#, el mecanismo de compuerta con reglas duras de negocio (\textit{Deterministic Guard}), el pipeline de validación en cascada en 4 fases, y el modelo de persistencia \textit{Dual-Track} que combina un registro inmutable en SQL relacional con almacenamiento de ultra-baja latencia en Redis.
\end{abstract}
